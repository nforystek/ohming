In the folder you will find a "Depreciated" folder, which will be already failed project experiment media.  You can ignore it or check it out, I mainly am just using it to backup prior attempts just incase I need something returned from them.

There is an ESP-01S folder, this is everything needed to flash an ESP-01S to the best firmware possible which was a rare find on the internet through massive exhaustive searching and testing the AT commands/manuals, finding various builds from mainly three different large playing companies in the market of and eventually choosing for very good reasons, an obscure downloaded firmware that was difficult to locate, as well, choosing a flashing software of about three of them.  There is a README.TXT in it's folder for more information.

The controller and the drone are named radio and flyer.  The FlyerArdunio folder holds the sketch project for the Arduino  of the drone.  The FlyerESP01S folder holds the sketch project for the ESP-01S of the drone, for after a the firmware is applied.  Likewise the RadioArdunio folder holds the sketch project for the Arduino  of the controller.  The RadioESP01S folder holds the sketch project for the ESP-01S of the controller, for after a the firmware is applied.

Any media in the root folder along with this file, is informational and should be kept up to date the best I can.
